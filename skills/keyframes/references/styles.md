# Style blocks

Paste one block under STYLE in the master prompt. Each names reference works for the model to aim at, then the
rules that make an image read as a frame from that medium rather than a generic AI illustration. Swap the world
and palette lines for the film; keep the rules.

## Photoreal space, large format

```
A frame from a big-budget space film shot on IMAX 65mm: true-to-life scale, real optics, deep blacks, natural
light only (the sun, city lights, the atmosphere's glow), believable colour, crisp detail, subtle film grain.
Wide 16:9 composition with one subject and a lot of black. No text, logos, UI or watermarks, nothing illustrated.
```

## Product hero, studio

```
A product hero shot from a premium launch film: the object in a real material (glass, anodised metal, ceramic),
lit by one large soft key and a thin hard rim light, reflections that describe its shape, a seamless dark
backdrop falling to black, macro depth of field. The object is sharp and the camera is low and close.
16:9. No text, logos or watermarks.
```

## Live-action cinematic

```
A still from a live-action feature film shot on a large-format digital cinema camera with anamorphic lenses:
natural skin, real fabric, practical light sources visible in frame, shallow depth of field, gentle halation on
highlights, fine film grain, a graded palette of two dominant colours. Composed like a cinematographer would,
not like a stock photo: no one looks at the camera, no studio backdrop. 2.39:1. No text, logos or watermarks.
```

## 3D animated feature

```
A frame from a modern 3D animated feature film: stylised characters with simple readable shapes, soft
subsurface skin, hand-painted textures, cinematic lighting with a warm key and cool fill, atmospheric depth,
a slight tilt-shift feel on wide shots. Characters keep the same proportions in every shot. 16:9. No text,
logos or watermarks.
```

## Stop-motion clay

```
A frame from a stop-motion clay animation film: hand-sculpted characters with visible thumbprints and tool
marks, miniature sets of real materials (card, felt, wood), small practical lights, shallow depth of field like a
macro lens, slight imperfection in every surface. 16:9. No text, logos or watermarks.
```

## Graphic novel ink

```
A panel from a graphic novel printed in two inks: heavy black brush shadows, one spot colour, halftone texture in
the mid-tones, bold silhouettes, dramatic angles, no gradients. Characters drawn with confident economical lines.
16:9. No text, speech bubbles, logos or watermarks.
```

## Pixel art game

```
A frame from a modern pixel-art game: a fixed limited palette, crisp pixels with no anti-aliasing or blur, readable
character sprites at a consistent pixel scale, parallax background layers, light drawn as dithered pixel bands.
16:9. No text, UI, logos or watermarks.
```
