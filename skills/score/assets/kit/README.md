# The bundled effects kit

The default sounds for `cues.py`, named by role. The clicks, keys, ticks and lands are public-domain recordings
(CC0 1.0): use them anywhere, no credit needed. The whooshes and hits are made by `make_kit.py` and share this
repository's MIT licence. Replace any role by putting your own files in a kit folder and passing it to `cues.py`.
